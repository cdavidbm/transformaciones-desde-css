1. Seleccionar por ID: getElementById()

Es el método más rápido para encontrar un elemento, ya que los IDs deben ser únicos en el documento.

// Selecciona el elemento con el id "parrafo-id"
const porId = document.getElementById('parrafo-id');
console.log(porId.textContent); // Muestra el texto del párrafo

2. Seleccionar por Nombre de Etiqueta: getElementsByTagName()

Devuelve una colección (HTMLCollection) de todos los elementos que coinciden con el nombre de la etiqueta especificada.

// Selecciona todos los elementos 

const porEtiqueta = document.getElementsByTagName('p');
console.log(porEtiqueta.length); // Muestra el número de párrafos encontrados
// Para acceder a uno, usamos su índice
console.log(porEtiqueta[0].textContent);

3. Seleccionar por Clase: getElementsByClassName()

Devuelve una colección (HTMLCollection) de todos los elementos que tienen la clase especificada.

// Selecciona todos los elementos con la clase "parrafo-clase"
const porClase = document.getElementsByClassName('parrafo-clase');
console.log(porClase.length); // Muestra el número de elementos con esa clase
// También se accede por índice
console.log(porClase[1].textContent);

4. Seleccionar con Selectores CSS: querySelector()

Es muy versátil. Devuelve el primer elemento que coincide con el selector CSS especificado. Puedes usar cualquier selector CSS (id, clase, etiqueta, atributos, etc.).

// Seleccionar el primer párrafo con la clase "parrafo-clase"
const queryClase = document.querySelector('.parrafo-clase');
console.log(queryClase.textContent);

// Seleccionar el párrafo anidado en un div
const queryAnidado = document.querySelector('div p');
console.log(queryAnidado.textContent);

5. Seleccionar Múltiples Elementos: querySelectorAll()

Devuelve una lista estática (NodeList) de todos los elementos que coinciden con el grupo de selectores CSS especificados.

// Selecciona TODOS los párrafos con la clase "parrafo-clase"
const queryTodos = document.querySelectorAll('.parrafo-clase');
console.log(queryTodos.length); // Muestra 2

// Podemos iterar sobre la lista de nodos con forEach
queryTodos.forEach(parrafo => {
    parrafo.style.color = 'blue'; // Cambia el color del texto a azul
});
