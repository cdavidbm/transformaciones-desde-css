Introducción al DOM con JavaScript

El DOM (Document Object Model) es una representación del documento HTML que nos permite interactuar con él desde JavaScript. Podemos leer, añadir, eliminar y modificar elementos y su contenido.

Ejercicio 1: Seleccionar y Modificar Contenido

JavaScript puede encontrar un elemento en tu página por su id único. Una vez que lo tiene, puede cambiar lo que dice adentro (con .innerHTML) o cómo se ve (con .style).

Explicación del código:

  • document.getElementById('parrafo-intro'): Busca en todo el documento HTML un elemento que tenga el id="parrafo-intro".
  • parrafo.innerHTML = "...": Cambia el contenido HTML del párrafo. Le estamos diciendo que ponga un nuevo texto, incluyendo la etiqueta <strong> para negrita.
  • parrafo.style.color = "green": Cambia el color del texto del párrafo a verde.
// Seleccionar elemento
const parrafo = document.getElementById('parrafo-intro');

// Modificar contenido y estilo
parrafo.innerHTML = "¡Modificado con JavaScript!";
parrafo.style.color = "green";

Este párrafo será modificado por el script al cargar la página.

Ejercicio 2: Manejar Eventos de Usuario (Clics)

JavaScript puede "escuchar" eventos que ocurren en la página, como un clic del ratón. Usamos .addEventListener() para decirle a un elemento (como un botón) qué función ejecutar cuando ocurra un evento específico.

Explicación del código:

  • boton.addEventListener('click', function() { ... }): Le estamos diciendo al botón que esté atento. Cuando un usuario haga 'click' en él, ejecutará el código que está dentro de function() { ... }.
  • Dentro de la función, seleccionamos otro párrafo y cambiamos su texto con .textContent.
const boton = document.getElementById('mi-boton');
const texto = document.getElementById('texto-a-cambiar');

boton.addEventListener('click', function() {
    texto.textContent = "¡El texto ha cambiado gracias a tu clic!";
});

Este es el texto original. Haz clic en el botón para cambiarlo.

Ejercicio 3: Crear y Añadir Nuevos Elementos

Imagina que tienes una caja de LEGO (la página) y quieres añadir un nuevo bloque. Con JavaScript, puedes crear un nuevo elemento HTML (un bloque) desde cero y luego decidir exactamente dónde ponerlo.

Explicación del código:

  • document.createElement('li'): Crea un nuevo elemento HTML, en este caso, una etiqueta <li> (un ítem de lista). En este punto, el elemento existe en la memoria de JavaScript, pero todavía no es visible en la página.
  • nuevoElemento.textContent = "Nuevo elemento": Le ponemos texto a nuestro nuevo <li>.
  • lista.appendChild(nuevoElemento): Tomamos el elemento <ul> que ya existía en la página (la lista) y le "añadimos como hijo" nuestro nuevo <li>. Esto hace que el nuevo elemento finalmente aparezca en la pantalla.
const lista = document.getElementById('lista-dinamica');
const nuevoElemento = document.createElement('li');
nuevoElemento.textContent = "Nuevo elemento";
lista.appendChild(nuevoElemento);

Ejercicio 4: Cambiar Atributos (ej. una imagen)

Podemos cambiar los atributos de un elemento, como el atributo src (fuente) de una imagen.

const imagen = document.getElementById('imagen-ejemplo');
imagen.src = 'URL_DE_NUEVA_IMAGEN';

Ejercicio 5: Alternar (Toggle) Clases de CSS

Con .classList.toggle(), podemos añadir o quitar una clase de CSS a un elemento, permitiéndonos cambiar su apariencia de forma sencilla.

const caja = document.getElementById('caja-toggle');
caja.classList.toggle('resaltado');
Haz clic en el botón para resaltar o quitar el resaltado de esta caja.

Ejercicio 6: Leer la Entrada (Input) de un Usuario

Podemos leer el valor de un campo de texto con .value y usarlo en nuestro script.

const input = document.getElementById('input-usuario');
const salida = document.getElementById('salida-input');
salida.textContent = 'Hola, ' + input.value;
