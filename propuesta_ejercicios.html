Propuesta de Ejercicios en Clase

A continuación, se presentan una serie de ejercicios basados en los temas vistos, para ser resueltos por los estudiantes.

Tema 1: Pseudoclases

  • Ejercicio 1: Replicar el efecto :hover visto en 1. pseudoclases/hover.html. Crea un botón que cambie de color de fondo y de texto cuando el cursor pase sobre él.
  • Ejercicio 2: Utilizar la pseudoclase :focus en un campo de entrada de texto. El borde del campo debe cambiar de color cuando el usuario haga clic en él, similar a 1. pseudoclases/focus.html.
  • Ejercicio 3: Dar estilo a un checkbox cuando está seleccionado usando :checked. Muestra un mensaje de "Aceptado" al lado del checkbox cuando esté marcado, como se ve en 1. pseudoclases/checked.html.

Tema 2: Pseudoelementos

  • Ejercicio 1: Añadir un ícono o una viñeta personalizada antes de cada elemento de una lista usando el pseudoelemento ::before, inspirado en 2. pseudoelementos/before.html.
  • Ejercicio 2: Insertar la palabra " (Fin)" al final de cada párrafo de un artículo utilizando el pseudoelemento ::after, como en 2. pseudoelementos/after.html.

Tema 3: Transformaciones

  • Ejercicio 1: Crea un div cuadrado y rótalo 45 grados al pasar el cursor sobre él, similar a 3. transformaciones/rotate.html.
  • Ejercicio 2: Diseña un botón que aumente su tamaño (escala) al 120% cuando el usuario interactúe con él, como se muestra en 3. transformaciones/scale.html.

Tema 4: Animaciones

  • Ejercicio 1: Crear una animación simple que haga que un círculo cambie de color de azul a rojo de forma infinita. Inspírate en los ejemplos de la carpeta 4. animaciones/.

Tema 5: Unidades CSS

  • Ejercicio 1: Diseñar una sección de "héroe" (hero section) que ocupe el 100% del alto y ancho del viewport, utilizando las unidades vh y vw. Puedes ver un ejemplo en 5. Unidades CSS/viewport.html.

Tema 6: Grid

  • Ejercicio 1: Construir un layout básico de una galería de 3 columnas utilizando CSS Grid, como en 6. Grid/grid_basico.html.
  • Ejercicio 2: Estructurar una página web simple con cabecera, contenido principal, barra lateral y pie de página utilizando grid-template-areas, basado en 6. Grid/grid_areas.html.

Tema 7: Formularios

  • Ejercicio 1: Crear y dar estilo a un formulario de registro simple (nombre, email, contraseña) como se muestra en 7. Formularios/estilos_desde_form.html.

Tema 8: Bootstrap

  • Ejercicio 1: Maquetar una sección de "Nuestros Servicios" con 3 tarjetas (cards) en una fila utilizando el sistema de grillas de Bootstrap. Revisa 8. bootstrap/bootstrap_grid_ejemplo.html como guía.

Tema 9: JavaScript (DOM)

  • Ejercicio 1: Crear una página con un botón y un párrafo. Al hacer clic en el botón, el texto del párrafo debe cambiar. Inspírate en 9. JS/DOM_intro_ejercicios.html.
  • Ejercicio 2: Desarrollar un contador simple con dos botones ("Incrementar" y "Decrementar") y un número que se actualice en la pantalla.
